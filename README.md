# MedMate 🩺

MedMate is an advanced AI-powered medical triage and patient dossier application. It leverages Large Language Models (LLMs) and Retrieval-Augmented Generation (RAG) to instantly parse medical documents, automatically update patient health profiles, and provide an intelligent triage chatbot for scheduling appointments.

## Features 🚀

- **Smart Document Parsing:** Upload prescriptions, lab reports, or medical certificates. MedMate uses AI Vision to extract structured data (vital signs, test results, active medications, allergies).
- **Auto-Updating Health Profile:** As new documents are uploaded, the AI automatically cross-references and safely updates the patient's longitudinal health record without overwriting verified historical data.
- **1-Click Emergency Dossier:** Generates a highly scannable, structured JSON-driven UI that groups active prescriptions, categorizes pending investigations, and surfaces critical medical alerts (e.g., severe allergies).
- **AI Triage Chatbot:** An empathetic, clinical-grade triage assistant that chats with the patient, assesses symptom severity against their RAG medical history, and books appointments with detailed clinical notes for the doctor.
- **Provider Portal:** Doctors can log in to view the highly detailed pre-consultation summaries generated by the AI, saving time during the actual visit.

## Tech Stack 💻

- **Frontend:** Next.js, React, Tailwind CSS, Lucide Icons, Axios
- **Backend:** FastAPI, Python, SQLAlchemy, SQLite
- **AI & Data:** LangChain, Google Gemini (Flash Lite / Vision), ChromaDB (Vector Store for RAG), PyPDF2

## Getting Started 🛠️

### Backend Setup
1. Navigate to the backend directory:
   ```bash
   cd backend
   ```
2. Create and activate a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Set up your `.env` file with your Gemini API key:
   ```env
   GOOGLE_API_KEY=your_api_key_here
   ```
5. Run the database seeder to initialize mock data:
   ```bash
   python seed.py
   ```
6. Start the FastAPI server:
   ```bash
   uvicorn main:app --port 8001 --reload
   ```

### Frontend Setup
1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the Next.js development server:
   ```bash
   npm run dev
   ```

Access the Patient Dashboard at `http://localhost:3000` and the Doctor Portal at `http://localhost:3000/doctor`.
